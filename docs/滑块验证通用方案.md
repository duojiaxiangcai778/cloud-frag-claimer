# 拼图滑块（「安全验证」）通用自动通过方案

> 适用：云服务「赚碎片兑云空间」点「安装」时弹出的风控滑块，以及其它长得一样的
> 「图片拼图 + 底部拖动条」验证码。
> 实现：`app/src/com/zcode/cloudfrag/Captcha.java`（Engine 在每次操作任务前都会调用）。

## 一、一句话原理

这类验证码的通过条件只有一条：**把拼图块拖到缺口上**。
所以整套流程就是「先比对位置 → 再滑动 → 再校验」：

```
截图 → 找照片区 → 找拼图块 → 找缺口 → 算 dx → 按住手柄拖过去 → 再抓界面看弹窗没了没
                    ↑                                                      │
                    └──────────── 没过就重来（每轮都是新图）───────────────┘
```

## 二、四个识别步骤（全部动态测量，不写死坐标）

| 步骤 | 判据 | 说明 |
|---|---|---|
| ① 照片区 | 找出「连续多行都大部分非白」的那段横向带 | 弹窗是白的、照片是花的，这是最稳的分割线 |
| ② 拼图块 | 半径 r 的圆环上 24 点够白（≥85%）**且** 环外 1.55r 处不够白（≤35%） | 后半条是灵魂：只要求"环上够白"的话，白色对话框背景也满足，会定位到标题文字周围 |
| ③ 缺口 | 盘内（r≈40）平均亮度 − 外圈（r≈88..130）平均亮度 < −0.18 | 照片背景再花，"暗进去一块"这个差值都很稳（实测 −0.39） |
| ④ 手柄 | 该行带内**最左**的连续纯白段，允许 ≤80px 空洞 | 手柄胶囊里有两个深色 ▶▶ 图标，不容忍空洞会被切成两段来回飘 |

## 三、参考几何参数（1264×2780 屏，逐像素量）

```
拼图照片区   y ≈ 1047..1550，x ≈ 110..1150
拼图块(白圈) 半径 ≈ 70，静止圆心 x ≈ 275（= 照片区左边缘 +165）
缺口(暗色盘) 半径 ≈ 66，与拼图块同一水平线
滑块手柄     白色胶囊 x ≈ 131..282、y ≈ 1625..1730 → 圆心 (206, 1674)
拖拽距离     dx = 缺口x − 拼图块x
```

代码里只有**亮度阈值**是标定的，几何量全部用比例和扫描得到，换分辨率不用改。

## 四、滑动手法（这是最容易翻车的一环）

```
input motionevent DOWN  hx hy
.... 26 段 MOVE（先快后慢的缓动 + ±1.5px 抖动）....
        └─ 到 92% 时截图，量一下拼图块实际到哪了
        └─ 误差 >5px 就补几段 MOVE 修正（闭环）
input motionevent UP    hx+dx hy
```

要点：

1. **不要用 `input swipe`**。它的轨迹由系统插值，密度不可控，实测快拖必被判机器，
   慢拖（5000ms）也只是偶尔过。
2. **`input motionevent` 可以跨进程保持按下状态**——DOWN / MOVE… / UP 分成多个
   adb/su 进程调用，触摸点仍然是按住不放的（实测拖页面位移 12.48%）。
   这样步数、每步时长、缓动曲线全部自己说了算。
3. **闭环校验**：拖到 92% 时截一张图，重新量拼图块的实际位置，算出跟缺口的误差再补拖。
   这一步能吃掉"手柄位移和拼图块位移不成 1:1"以及各种累积误差。
4. **失败必换图**：一轮没过，拼图会换成另一张照片、缺口也换位置，
   所以每一轮都必须**重新截图重新定位**，拿上一轮的 dx 重试毫无意义。

## 五、怎么调试 / 怎么确认还准

1. App 主界面新按钮 **「滑块自检」**：只识别、不拖动，把
   `屏幕尺寸 / 照片区 / 拼图块 / 缺口 / 手柄 / 建议 dx` 全部打到日志里。
   没有弹窗时会明确说「未找到拼图照片区」。
2. 滑块连续失败时，App 会自动把现场图存到
   `/sdcard/cf_captcha_fail_<轮次>.png`，拉下来就能按第四节参数复算。
3. 换手机/换分辨率后，先点一次「滑块自检」，看照片区、缺口、手柄三项是否合理；
   不合理再调 `RING_MIN/RING_MAX`（环半径范围）和 `GAP_DELTA`（缺口暗度阈值）。

## 六、已知边界

- `input motionevent` 需要 Android 11+；老机器会自动退回 `input swipe` 慢拖。
- 遇到风控打标时（页面提示存在风险、要求先完成安全验证），滑块只是第一道门，
  过了之后安装类任务仍可能不触发，这是账号侧限制，不是这段代码能解决的。
- 拼图块如果被裁到照片区正中间（左半边找不到），会退化成"照片区左边缘 +165"兜底。
