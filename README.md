# 云服务领碎片助手

一加 / OPPO 手机「云服务」App 里有个活动叫「做任务免费领云空间」（页面标题：赚碎片兑云空间）：
做完里面的安装体验任务就给几块碎片，碎片可以兑云空间容量。任务全是「装个推广 App、打开挂一会儿、
回来点领取」，量多又枯燥，所以写了这个工具自动跑完。

做法是走 root：`su` + `uiautomator dump` 读界面 + `input` 点按，**不需要无障碍服务，也不 hook 或改动宿主 App**。
跑完一条任务的完整链路是：

```
云服务首页 → 进「赚碎片兑云空间」→ 找到可做的卡片 → 点安装 → 等装完 → 拉起 App 停留十几秒
→ 回到云服务 → 点领取 → 校验卡片消失 → 下一条
```

## 板块

任务页从上到下分三个板块，App 界面上各对应一个勾选项：

| 板块 | 内容 | 界面开关 |
|---|---|---|
| **今日推荐** | 页面顶部三个圆形推荐位（抖音、同程、1688 之类）。按钮文案是「重新安装 / 立即注册 / 开始安装」，不是普通 Button 控件，得单独识别 | 也做「今日推荐」板块（默认关） |
| **中间板块** | 「连续 2 天体验」+「先安装再注册」两组。前者要连续两天各打开一次才算首日奖励，后者安装完还得去注册 | 做中间板块（默认开） |
| **日常任务** | 页面最下方的安装 / 打开类任务 | 做「日常任务」板块（默认开） |

三块的任务卡片分散在整页约 2.5 屏里，程序是整页逐屏扫描的，不只看当前屏。

## 用法

1. 用 `python build.py` 生成 `dist/云服务领碎片.apk` 并安装（需要 root）
2. 首次装完给一次悬浮窗权限：
   `adb shell appops set com.zcode.cloudfrag SYSTEM_ALERT_WINDOW allow`，或手点允许
3. 打开 App → 按需改「打开后等待秒数 / 最多领取次数 / 最长运行分钟 / 安装最长等待秒」
4. 勾选要跑的板块（勾选状态持久化，重装 APK 会读回旧值）→ 点「开始自动领取」
5. 跑的时候别动手机；可勾「全部完成后自动退出本 App」

界面上另有几个调试按钮：「自检」（root 状态 / 当前前台包 / 界面节点数）、
「滑块自检」（只识别滑块不拖动）、「导出界面」、「导出日志到 Download」。

## 构建

```
python build.py
```

不依赖 Gradle：`aapt2 → javac → d8 → zipalign → apksigner`。
需要 Android SDK（build-tools 34）与 JDK 21，改 `build.py` 顶部几个常量指向自己的路径即可；
产物输出到 `dist/`，同时复制一份到项目根目录。


## 关于滑块

点安装时有概率弹出「安全验证」拼图滑块。处理逻辑在 `Captcha.java`，思路写在
`docs/滑块验证通用方案.md`：截图 → 找照片区 → 找拼图块 → 找缺口 → 算 dx →
`input motionevent` 分段缓动拖过去（中途截图闭环修正）→ 再抓界面确认弹窗消失。
所有几何量都是动态测量，不写死坐标，换分辨率不用改代码。
